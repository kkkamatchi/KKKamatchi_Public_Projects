# KKKamatchi Public Projects

Open-source projects on production ML and MLOps, built in public. Each folder is a self-contained project with its own README, tests and CI.

| Project | What it is |
|---|---|
| [`market-ml`](market-ml) | Production ML on market data: open tools, honest benchmarks and MLOps projects. First release: [`india-costs`](market-ml/packages/india-costs), charges on Indian equity trades from dated rate tables. |

Repository-wide rules: no market data or model weights are committed (CI blocks them; see [`market-ml/DATA_POLICY.md`](market-ml/DATA_POLICY.md)), and nothing here recommends buying or selling anything.

Educational engineering content. Not investment advice. Code is licensed under [Apache-2.0](LICENSE).
